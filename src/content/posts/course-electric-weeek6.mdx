## Lec12 组合逻辑设计

### 从逻辑到门

与或式天然对应**两级逻辑**。两级逻辑的第一级是**与门**，第二级是一个或门，把所有第一级与门的输出「加」起来。例如:

$$
Y = \overline\{A\}\\,\overline\{B\}\\,\overline\{C\} + A\\,\overline\{B\}\\,\overline\{C\} + A\overline\{B\}C
$$

其对应的电路原理图如下，三个最小项各配一个**三输入与门**，输出送进一个三输入或门。并且，需要注意的是，输入端的反变量由反相器产生。

<figure>
  <img src="/electric/week6/dlylt.png"/>
  <figcaption>电路原理图</figcaption>
</figure>

在画原理图时有一套约定俗成的规矩：

- 输入放在**左边或顶部**，输出放在**右边或底部**
- 信号流向**从左到右**，门一律朝右
- 连线尽量走直线，少拐弯
- 线的连接只允许两种形式：**T 型接头**、**交叉处画实心圆点**；交叉但没有圆点表示**不相连**。

此外，一个电路可以有**多个输出**，它们共享同一组输入与中间结点。

### 多级组合逻辑

很多情况下，两级逻辑并不总是最优解。门电路除了**门数**，还要关心每个门的**扇入**，即输入个数。除此之外，有时还需要考虑**延迟**和**功耗**。举个简单的例子：

$$Y = ABC + ADE$$

- **两级实现**：两个三输入与门以及一个两输入或门，共 3 个门
- **多级实现**：$Y = A(BC + DE)$，先用两个与门算出 $BC$ 与 $DE$，再接或门，最后与 $A$ 相与

可以看出，后者的门数虽然增多了，变成 4 个，但是所有门的扇入都为 2。一个自然的问题是：门数变多了，为什么这样做还值得？因为在真实工艺里，**扇入大的门更慢、更贵**。CMOS 电路里这一点尤其明显，与非门和或非门是天然的结构，而**与门、或门都要额外加一级反相器**，所以实际设计里更倾向于用与非/或非再加 De Morgan 变换来搭电路。

>[!note] 判断多级结构优劣的一般标准
> **门数量最少、速度最快、功耗最低**，三者往往互相冲突，需要权衡。

### X 和 Z

数字电路里除了 0 和 1，还有两个**非逻辑值**。

**竞争值记作 $X$。** 如果同一个结点同时被某个门的 1 和另一个门的 0 驱动，这个结点的真实电压会落在 $0 \sim V\_\{dd\}$ 之间，随电压、温度、时间和噪声漂移，同时带来很大的短路功耗。这种情况在真值表与波形里统一记作 $X$。通常情况下，当电路中出现了 $X$ 时，我们认为该电路有 bug。

> [!warning] 两个不同意义的 $X$
> 真值表里的 $X$ 表示**无关项**，意思是我们并不关心某项的取值，即某项的取值对结果不造成任何影响；而电路里的 $X$ 表示**竞争**。二者为同一个符号，但却是两种截然不同的含义，需要看上下文区分。竞争几乎总是 bug 的信号，而无关项是化简的资源。

**浮空值记作 $Z$。** 如果一个结点既没有被高电平驱动，也没有被低电平驱动，它就叫**浮空**，值记为 $Z$，即高阻态。高阻态下的电压可能是 0、1，也可能在两者之间。

    { src: "/electric/week6/sthcq.png", caption: "三态缓冲器" },

/>

产生 $Z$ 的典型器件是**三态缓冲器**：除数据输入 $A$ 之外还有一个**使能端 $E$**，$E = 0$ 时输出为 $Z$，即「断开」。

| $E$ | $A$ | $Y$ |
| --- | --- | --- |
| 0 | 0 | $Z$ |
| 0 | 1 | $Z$ |
| 1 | 0 | 0 |
| 1 | 1 | 1 |

$Z$ 的用处是「**三态总线**」。多条芯片的输出挂在同一根共享总线上，每个芯片都通过一个三态缓冲器接入，**任意时刻只允许一个芯片使能**，其余全部输出高阻，总线上的值就由那一个芯片决定。如果两个芯片同时使能而且值不同，就退化成上面的竞争 $X$。这正是总线设计里最容易出错的地方。

### 卡诺图

这部分内容考试不会涉及，感兴趣的了解即可 ～

布尔代数化简靠公式一条条变，容易漏项。**卡诺图（K-map）**把真值表重新排布成二维网格，让「可以合并的最小项」转变为图上的**相邻**关系，从而用「瞪眼法」圈出最简式。

它的三条基本规定是：

- 卡诺图的**每个方格对应真值表的一行**，也就是一个**最小项**
- 行、列的顺序按**格雷码**排列（$00, 01, 11, 10$），保证相邻两格**只有一个变量不同**
- 卡诺图是**环绕**的：最右一列与最左一列、最上一行与最下一行也算相邻

>[!note] 如何在卡诺图中圈出最小项
>1. 用**最少的圈**把所有 $1$ 都圈住，圈里只能有 $1$；
>2. 每个圈必须是**矩形**，边长只能是 $1, 2, 4, 8$；
>3. 每个圈都要**尽量大**（圈越大，消掉的变量越多）；
>4. 圈**可以跨边界环绕**；
>5. 同一个 $1$ **可以被多个圈重复圈中**（允许重叠，只要圈的总数最少）。

例如，对于四输入真值表，化为卡诺图后：

<figure>
  <img src="/electric/week6/kmap.png"/>
  <figcaption>四输入卡诺图</figcaption>
</figure>

可以很简单地得到该真值表对应的四输出布尔表达式：

$$
  Y = \overline\{A\} C + \overline\{A\} BD + A\overline\{B\} \\, \overline\{C\} + \overline\{B\} \\, \overline\{D\}
$$

还有一类情况：真值表里某些输入组合**根本不会出现**，这些格子里的值可以任意填，叫作**无关项**。化简时把它们当 $1$ 用来凑大圈，可以实现更简的结果，但它们**不影响**最终函数的正确性。当然，卡诺图只适合变量少的情形。现代工程实践里，大规模电路一律交给**逻辑综合**工具（如 Synopsys Design Compiler），人工化简只在小规模电路或理解原理时使用。

### 组合逻辑模块

组合逻辑模块是构成组合逻辑的单位，是这一章节中较为重要的内容。需要重点掌握**加法器、选择器和译码器**的 spec 以及功能。

#### 加法器

<ImageRow
  images={[
    { src: "/electric/week6/bjqspec.png", caption: "半加器 spec" },
    { src: "/electric/week6/qjqspec.png", caption: "全加器 spec" },
  ]}
/>

三类组合逻辑模块中，加法器又可以分为**半加器**和**全加器**。半加器电路是指对两个输入数据位相加，输出一个**结果位**和**进位**，**没有进位输入**的加法器电路，是实现两个一位二进制数的加法运算电路。

| $A$ | $B$ | $C$ | $S$ |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 0 |
| 0 | 1 | 0 | 1 |
| 1 | 0 | 0 | 1 |
| 1 | 1 | 1 | 0 |

从真值表可以直接读出：

$$S = A \oplus B, \\, \\, \\, \\, \\, \\, \\, \\, \\, C = AB$$

因此，一个异或门加上一个与门就可以组成半加器电路。半加器不能处理低位来的进位，加上 $C\_\{in\}$ 之后就可以变成**全加器**：

$$
S = A \oplus B \oplus C\_\{in\}, \\\\[1em]
C\_\{out\} = AB + AC\_\{in\} + BC\_\{in\} = AB + (A + B)C\_\{in\}
$$

把 $N$ 个全加器串起来，低位的 $C\_\{out\}$ 接高位的 $C\_\{in\}$，就得到**行波进位加法器**。它结构极简单，但缺点也很致命：**最高位的进位必须等前面所有位都算完**，延迟随位宽线性增长。


#### 选择器

从多个输入信号挑选某一个进行输出的器件叫做**选择器（Mux）**。其中，最简单的情况就是仅有两个输入 $D\_0$ 和 $D\_1$：

$$
Y = \overline\{S\}\\,D\_\{0\} + S\\,D\_\{1\}
$$

最简单的二路选择器可以由三态缓冲器构成。而$4:1$的多路选择器则较为复杂，需要用到两位选择信号。既可以写成两级逻辑中的与或式，也可以用层次结构，由三个二路选择器拼接出来。后者门数更少，也更符合模块复用的思路。

选择器还有一个非常好用的隐藏功能：**它本身就能实现任意逻辑**。在考虑这部分问题时，一个通用的技巧是将真值表按照选择器输入-输出比例切分，然后化简真值表。（详见课件 P146-P151）

#### 译码器

译码器通常有 $N$ 位输入、$2^N$ 个输出，每个输出对应**一个最小项**。输入等于某个编码时，只有对应的输出为 1，其他均为 0。

### 时序

截至目前，我们考虑的都是组合逻辑以及组合逻辑器件的功能，也就是**逻辑值的正确与否**。但真实电路里信号传播需要时间，**输出相对输入什么时候有效**同样重要，这就是时序规范。

电路时序问题中，最基本的两个量是：

- **传输延迟 $t\_\{pd\}$**：从输入变化到**所有**输出都到达最终值所需的最长时间（最坏情况）
- **最小延迟 $t\_\{cd\}$**：从输入变化到**任意**输出开始变化所需的最短时间（最好情况）

两者之所以不同是因为，连线和门都有 RC 充放电时间，并且上升沿与下降沿的延迟不一样，不同路径经过的门数不同，温度也会产生影响。

<figure>
  <img src="/electric/week6/yc.png"/>
  <figcaption>两类延迟</figcaption>
</figure>

把每个门的延迟加起来，最**长**的那条输入到输出的路径叫**关键路径**，和离散数学中工序问题中的关键路径的思想相同；最**短**的那条叫最短路径，它在之后时序逻辑的「保持时间」时会变成约束条件。所以，在设计中，我们真正关心的往往是**最坏情况延迟**，因此优化也要优先考虑关键路径。

<figure>
  <img src="/electric/week6/lj.png"/>
  <figcaption>两类路径</figcaption>
</figure>

在考虑上述电路的关键路径时（假设导线无延迟，两个与门延迟相等），关键路径上所有的延迟相叠加，就可以得到传输延迟：

$$
  t\_\{pd\} = 2 \cdot t\_\{pd&#92;&#95;\mathrm\{AND\}\} + t\_\{pd&#92;&#95;\mathrm\{OR\}\}
$$

延迟还会带来一个非常隐蔽的问题：同一个信号经过不同路径到达同一个门时，会因为延迟不同而在输出上**短暂地闪一下**，这就是**毛刺**。

<figure>
  <img src="/electric/week6/glith.png"/>
  <figcaption>毛刺</figcaption>
</figure>

以 $Y = \overline\{A}\\,\overline\{B} + BC$ 为例：稳态下 $A = 0, B = 1, C = 1$ 时，两个乘积项分别输出 0 和 1，$Y$ 应是 1。但当 $B$ 从 1 变化到 0 时，$BC$ 这一项会先变为 0，$\overline\{A}\\,\overline\{B}$ 之后才会变为 1。期间，$Y$ 会短暂地变为 0，出现一个本不该有的负脉冲。

需要强调的是：在**同步电路**里，毛刺大多会被时钟「消化」掉，并不总是致命的；但如果毛刺直接送进了时钟端、复位端或异步输入，就会变成真正的 bug。
